# DAVIS project homepage

This static project page adapts the [GALATEA `gh-pages` template](https://github.com/boyuan-an/GALATEA/tree/gh-pages) for DAVIS: *A Depth-Only End-to-End Active-Vision Framework for Humanoid Soccer Skills*.

## Local preview

```powershell
python .\serve.py --host 127.0.0.1 --port 8000
```

Open <http://127.0.0.1:8000/index.html>.

The page uses selected, lightweight figures from `CoRL/DAVIS_CoRL` and links to the paper and rebuttal PDFs in `resources/`. Large raw demonstration archives and videos remain in the source workspace and are intentionally not copied into this static site.
